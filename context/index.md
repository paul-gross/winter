# Contributor context

What a contributor reads before changing this repository. The tree has four areas, each with an index that routes to its
documents. [AGENTS.md](../AGENTS.md) holds the rules that apply to every change.

| Area                                    | Read when                                                                   |
| --------------------------------------- | --------------------------------------------------------------------------- |
| [architecture](./architecture/index.md) | You need to know how the code is divided, or where a change belongs.        |
| [standards](./standards/index.md)       | You need the rules that Rust code and tests in this repository are held to. |
| [tooling](./tooling/index.md)           | You need to run something: the bootstrap, a gate, the formatter.            |
| [verification](./verification/index.md) | You verify a feature or recovery behavior and need its methods.             |
