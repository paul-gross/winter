title: Set up a workspace
---

The `setup` topics guide setting up a workspace. Each is safe to follow again on a workspace that is partly set up.

- Read `winter-workspace context setup/walkthrough` to set up a workspace from an empty directory, step by step.
- Read `winter-workspace context setup/contributing` to write the workspace's contributing guide.
- Read `winter-workspace context setup/project-setup` to write the workspace's project setup guide.
